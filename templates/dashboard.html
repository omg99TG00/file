Info & Tutorial

This is a shared OwO farming panel. You log in with a provided account, attach one Discord user token and one channel, then run timed farm sessions.

Quick start

  1. Open Deployments → New deployment.
  2. Paste a valid Discord user token and the target channel ID. Both are validated live.
  3. Open your deployment. Set HuntBot and Speed as you like (saved permanently).
  4. Toggle Farm ON. If a global slot is free, farming starts for 3 hours.
  5. When time ends, Farm turns OFF and locks for 3 hours before you can start again.

Rules

  • One deployment per account. Delete to replace token/channel.
  • Only 3 farms can run at once across everyone. If full, wait and try later.
  • Tokens must be unique. Channels may be shared.
  • If a token dies later, delete the deployment and create a new one.

Speed modes

lifetime (default, safest cadence), durable, efficient, fast.

Use responsibly. This tool is for practice on accounts you control.
